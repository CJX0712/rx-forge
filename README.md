# RxForge — 正则铁路图锻造炉

单文件、零依赖、离线运行的正则表达式可视化工具：把正则解析成 AST，用 **Thompson 构造**编译成 ε-NFA，并渲染成经典**铁路图**（syntax diagram）。内置实时匹配测试与不变量自检。

## 打开方式

直接双击 `index.html`（或任意浏览器打开），无需服务器、无外部请求。

## 功能

- **铁路图渲染**：字符 = 圆角框，`|` = 分叉轨道，`*` = 回环轨道 + 底部直通轨道，`+` = 回环轨道，`?` = 底部旁路轨道；绿点 = 起点，红双圈 = 接受态。
- **实时匹配**：输入测试串即时显示 ✓/✗，NFA 模拟引擎驱动。
- **内置自检**：页面底部一键运行 11 组不变量校验。

## 支持的语法

`字符字面量` · `\` 转义（含 `\.` 等字面元字符） · `.` 任意单字符 · `|` 或 · `()` 分组 · `*` `+` `?` 后缀（可叠加）

## 引擎与验证（`_smoke.js`，11/11）

| 不变量 | 说明 |
|---|---|
| 已知向量 | 43 例正则 × 字符串匹配断言 |
| Thompson 状态数公式 | `nStates = 2·(alt+star+plus) + 1·(opt+cat) + 2`，10 模式逐一核对 |
| **交叉验证** | 与 JS 原生 RegExp 引擎对比，6 模式 × 1500 随机串，结果全一致 |
| ε-闭包性质 | 幂等 `closure(closure(S))==closure(S)`、单调 `S⊆T ⟹ closure(S)⊆closure(T)`、有序无重复 |
| 确定性 | 重复运行结果与闭包轨迹逐位一致 |
| 解析器健壮性 | 6 种畸形模式必抛错 |
| 图结构 | SVG 尺寸/标签/起终点合法 |

## 结构

```
index.html   引擎（parse → toNFA → epsilonClosure/step/accepts → diagram）+ UI + 自检
_smoke.js    无头校验（Node vm 提取引擎运行）
_probe.js    AST/NFA 结构探针
```

## 本轮踩坑记录

- `\.` 字面量与 `.` 通配在转移表里撞标记 → 用显式 `any` 布尔位区分
- Thompson 状态数公式初版漏了 `cat` 的合并态与 `alt` 右支 —— 独立重算公式对照才抓得住
